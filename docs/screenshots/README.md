# Screenshot guide

Add real screenshots to this directory, then uncomment the screenshot block in the [root README](../../README.md#screenshots). There are no screenshot images checked in yet; no mockups are presented as product screenshots.

| Filename | Capture |
| --- | --- |
| `reveal.png` | The parchment landing screen before revealing the map |
| `sign-in.png` | The themed sign-in screen with no real credentials entered |
| `live-map.png` | Map with two demonstration accounts sharing named footsteps |
| `mobile-map.png` | Optional mobile view using HTTPS |

## Capture checklist

1. Open the live deployment or a working local setup.
2. Use a consistent desktop viewport, around 1440 × 900, with 100% browser zoom.
3. Hide developer tools and wait for fonts, map tiles, and animations to settle.
4. Use sample names and a public, non-sensitive location. Avoid revealing home addresses, real-time personal coordinates, or credentials.
5. Save PNGs under the filenames above. Optimize unnecessarily large files without making text unreadable.
6. Uncomment the README embeds and preview them on GitHub. Add descriptive alt text for extra screenshots.

The main map image should show the privacy/sharing panel and footstep banners together. The reveal image makes a good full-width opening image; the sign-in and map images are arranged side by side in the prepared table.
